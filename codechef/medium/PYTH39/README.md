## Problem

### Strings and Integers

Listen

Python uses the + sign for both addition and concatenation.

- Numbers are added.
- Strings are concatenated.
- We cannot mix the two
### Task

You are given a program which does the following

- You want to output 2569
- Try running the given code given in the IDE as it is - it will give a Compilation error
- Fix the error so that both the variables become strings and the output is 2569

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-17T10:08:28.756Z  

```py
# Solution as follows

string1 = "25"
string2 = "69"

print(string1 + string2)

'''
The code provided in IDE is trying to concatenate two different types
of data: a string (string1) and an integer (string2). 
To fix this, you need to convert the integer to a string before concatenating. 
Wraping it with double quotes makes it string. 
'''
```
