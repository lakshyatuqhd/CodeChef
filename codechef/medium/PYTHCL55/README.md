## Problem

### Hello user

Listen

Write a program which does the following

- Declare a string variable x
- Accept a text user input - the name of the user - and store it in the variable x
- Output and print to the console Hello before the user defined name. Remember to add a space between Hello and x
### Sample 1:
Input
Output

```
Chef
```

```
Hello Chef
```

### Sample 2:
Input
Output

```
Chefina
```

```
Hello Chefina
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-17T10:37:21.816Z  

```py
# Solution as follows

x = input()     # Remember that input() is necessarily a string

print("Hello", x)
```
